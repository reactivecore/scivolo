Scivolo

A Scala 3 REPL, interpreted in your browser. No threads, files or extra libraries.

Source on GitHub · Reactive Core GmbH

Enter runs the input once it is complete, Shift+Enter adds a line, Tab completes, ↑ and ↓ walk the history.

Run compiles the file and runs its main method, or its top-level statements as a script (Ctrl+Enter); Tab indents. The file stays in this browser.
